# BackAppHelp  

**BackAppHelp** es un backend diseñado para gestionar y ofrecer soporte técnico a usuarios de una aplicación. Este proyecto está construido con **Spring Boot** y se centra en proporcionar una API robusta para la gestión de usuarios, tickets de soporte y estadísticas de rendimiento.  

---

## 🚀 Características principales  
- **Gestión de usuarios:** Crear, actualizar, y eliminar perfiles de usuarios.  
- **Gestión de tickets:** Registrar, asignar y cerrar tickets de soporte técnico.  
- **Autenticación y seguridad:** Implementación de JWT para la autenticación de usuarios.  
- **Estadísticas:** Generación de reportes sobre el tiempo de resolución de tickets.  

---

## 🛠️ Tecnologías utilizadas  
- **Lenguaje:** Java 17  
- **Framework:** Spring Boot 3  
- **Base de datos:** PostgreSQL  
- **Seguridad:** Spring Security con JWT  
- **Herramientas:** Maven, Swagger para la documentación de la API
